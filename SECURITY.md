# Security

This repository contains instructions and installers, not patient data or model credentials.

- Review changes to `SKILL.md`, installer scripts, and `upstream-skills.lock.json` before updating.
- The installers connect only to the two declared GitHub repositories and verify the checked-out commit IDs.
- Existing skill directories are moved to timestamped local backups before replacement.
- Do not put PHI, credentials, unpublished manuscripts, or proprietary model artifacts in this repository.
- Do not authorize external LLM, plotting, telemetry, or hosted RAG services for confidential clinical material without an explicit policy review.

Report security concerns privately to the repository owner rather than opening an issue containing sensitive details.
